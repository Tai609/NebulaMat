# OVITO Resources

> Load this when: local references do not cover a modifier, file format, renderer, or installation issue.

- **OVITO website and install links** - https://www.ovito.org/ - official package entry point for desktop application and Python module.
- **OVITO Python Reference** - https://www.ovito.org/manual/python/ - authoritative API documentation for pipelines, modifiers, data objects, export, and rendering.
- **Python module installation** - https://www.ovito.org/manual/python/introduction/installation.html - official notes on the standalone module and `ovitos`.
- **Modifiers overview** - https://www.ovito.org/manual/reference/pipelines/modifiers/index.html - official list of analysis and visualization modifiers.
- **Create Bonds modifier** - https://www.ovito.org/manual/reference/pipelines/modifiers/create_bonds.html - official description of automatic and pairwise bond generation.
- **OVITO viewport rendering API** - https://www.ovito.org/manual/python/modules/ovito_vis.html - official API reference for viewports and renderers.
- **Common Neighbor Analysis** - https://www.ovito.org/manual/reference/pipelines/modifiers/common_neighbor_analysis.html - official description of CNA and intended use.
- **Wigner-Seitz defect analysis** - https://www.ovito.org/manual/reference/pipelines/modifiers/wigner_seitz_analysis.html - official description of vacancy/interstitial counting with a reference state.
- **ASE I/O** - https://wiki.fysik.dtu.dk/ase/ase/io/io.html - official ASE documentation for reading and writing structure files, including image output.
- **PyPI package** - https://pypi.org/project/ovito/ - supported Python/platform matrix and pip install command.
- **OVITO community forum** - https://matsci.org/c/ovito/ - practical troubleshooting for import, rendering, and scripting issues.

Do not copy manual pages into this repository. Summarize local procedures with links and keep scripts reproducible.
