# DeePMD Examples

Place small, privacy-neutral DeePMD examples here:

- `00.data/` with tiny dpdata-formatted toy train/validation sets.
- `input.json` templates for one-component and multi-component systems.
- `in.lammps` examples using `pair_style deepmd`.

Do not commit proprietary model files, large AIMD trajectories, licensed data, or real project paths.
