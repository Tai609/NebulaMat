# Multiwfn Examples

Verified examples only. Each example must include:

- upstream calculation provenance and validation status;
- input wavefunction/data file type used by Multiwfn;
- Multiwfn version and exact menu path/options;
- expected output summary and any generated small tables/figures;
- what to adapt and what not to generalize.

Do not commit bulky cube files, screenshots, or binary checkpoints. Use compact excerpts and reproducible instructions.
