# VASPKIT Resources

> Load this when: local references do not cover a VASPKIT menu option, installation variable, citation, or feature change.

- **VASPKIT documentation overview** - https://vaspkit.com/ - official entry point; states the tool supports interactive and command-line use for VASP post-processing.
- **Installation guide** - https://vaspkit.com/installation.html - official setup notes for unpacking VASPKIT and configuring `~/.vaspkit`.
- **Feature list / task IDs** - https://vaspkit.com/features.html - official task catalogue; use this instead of memorized task numbers when version matters.
- **Tutorials** - https://vaspkit.com/tutorials.html - official examples; useful for menu sequences, but treat scientific choices as examples to validate.
- **Release notes** - https://vaspkit.com/changelog.html - check when task IDs or output formats differ across versions.
- **SourceForge download page** - https://sourceforge.net/projects/vaspkit/ - release downloads and high-level capability list.
- **VASP wiki** - https://vasp.at/wiki/The_VASP_Manual - authoritative VASP-side meaning of files and INCAR tags used by VASPKIT.

Do not commit downloaded manuals, POTCAR files, or copied web pages. Distill needed procedures into `running.md`, `validation.md`, or `errors.md` with a source link.

- **NIST-JANAF thermochemical tables** — https://janaf.nist.gov/ — experimental gas thermochemistry for chemical potentials; use with explicit reference-state reconciliation.
