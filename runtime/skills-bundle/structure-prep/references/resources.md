# Structure-Prep Resources

> Load this when: a question isn't covered by the local references — consult the linked source, then distill the answer back into the topical file.

- **pymatgen docs** — https://pymatgen.org/ — Structure/Slab/defect APIs; `pymatgen.io` for every format.
- **RDKit docs** — https://www.rdkit.org/docs/ — embedding parameters, conformer generation, sanitization rules.
- **ASE** — https://wiki.fysik.dtu.dk/ase/ — alternative IO and building tools; sometimes reads what pymatgen won't.
- **Materials Project** — https://next-gen.materialsproject.org/ (+ API) — relaxed structures with entry IDs for provenance.
- **COD** — https://www.crystallography.net/cod/ — open crystallographic structures from experiments.
- **ICSD** — https://icsd.products.fiz-karlsruhe.de/ — licensed; the standard source for XRD-matched experimental phases.
- **Bilbao Crystallographic Server** — https://www.cryst.ehu.es/ — space-group machinery, Wyckoff positions, symmetry relations.
