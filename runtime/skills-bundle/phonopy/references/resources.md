# Phonopy Resources

> Load this when: a question isn't covered by the local references — consult the linked source, then distill the answer back into the topical file.

- **Phonopy documentation** — https://phonopy.github.io/phonopy/ — authoritative for all conf tags, interfaces (VASP/QE/...), and the NAC/BORN workflow.
- **Phonopy examples repo** — https://github.com/phonopy/phonopy/tree/master/example — worked examples per code interface.
- **phono3py** — https://phonopy.github.io/phono3py/ — anharmonic (thermal conductivity) extension when harmonic isn't enough.
- **seekpath** — https://seekpath.readthedocs.io/ — standardized high-symmetry k-paths.
- **PhononDB (Togo)** — https://github.com/atztogo/phonondb — reference phonon results to sanity-check against.
