# MLP Resources

> Load this when: a question isn't covered by the local references — consult the linked source, then distill the answer back into the topical file.

- **DeePMD-kit docs** — https://docs.deepmodeling.com/projects/deepmd/ — input.json schema, training, compression, LAMMPS interface.
- **dpdata** — https://docs.deepmodeling.com/projects/dpdata/ — format conversions and supported DFT outputs.
- **DP-GEN** — https://docs.deepmodeling.com/projects/dpgen/ — active-learning workflow configuration and model-deviation selection.
- **MACE** — https://mace-docs.readthedocs.io/ and https://github.com/ACEsuit/mace — training configs, foundation models (mace-mp), LAMMPS export.
- **Materials Project / Matbench Discovery** — https://matbench-discovery.materialsproject.org/ — foundation-model benchmark context (what mace-mp-class models are good at).
- **ASE calculators** — https://wiki.fysik.dtu.dk/ase/ — driving MLPs for EOS/phonon/NEB validation tasks without LAMMPS.

Foundation-model checkpoints have licenses and version identities — record the exact checkpoint name/hash in provenance.
