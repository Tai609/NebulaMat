# CatMAP Resources

> Load this when: local references are insufficient and official CatMAP documentation, source examples, or microkinetic-method background is needed.

- **CatMAP documentation** — https://catmap.readthedocs.io/en/latest/ — official tutorials and API notes for creating microkinetic models, descriptors, scalers, and analyzers.
- **CatMAP source** — https://github.com/SUNCAT-Center/catmap — source code, examples, data tables, and issue history.
- **CatMAP tutorial: creating a microkinetic model** — https://catmap.readthedocs.io/en/latest/tutorials/creating_a_microkinetic_model.html — model setup concepts and file patterns.
- **JANAF/NIST** — https://janaf.nist.gov/ — gas thermochemistry cross-checks for input free energies.

When distilling external documentation into this skill, paraphrase the operational rule and link the source. Do not copy long manual sections.
