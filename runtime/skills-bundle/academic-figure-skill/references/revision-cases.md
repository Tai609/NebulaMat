# Reviewer Revision Case Studies

Real cases of figures that were flagged during peer review and how they were fixed. Each case follows a structured format for LLM retrieval: **Problem → Reviewer Comment → Fix → Lesson**.

---

## Case 1: Heatmap — Default Red-Blue Colormap

**Figure Type:** Gene expression heatmap (R/ComplexHeatmap)
**Target Journal:** Nature Genetics

**Problem:** Used ComplexHeatmap's default red-white-blue color scale with sharp transitions. Row names for 500+ genes made labels unreadable.

**Reviewer Comment:** "The heatmap color scale makes it difficult to discern subtle expression differences. The row labels are illegible. Please improve readability."

**Fix:**
1. Switched to `colorRamp2` with explicit breakpoints: `c(-2, 0, 2)` → `c("#2166AC", "#F7F7F7", "#B2182B")`, creating smoother transition through neutral white
2. Reduced displayed genes to top 50 (by variance), annotated with `row_annotation` for key pathways
3. Set `row_names_gp = gpar(fontsize = 5)` for the reduced set, making labels readable at print size

**Lesson:** The first thing a reviewer checks on a heatmap is whether they can actually read it. Default color scales with sharp transitions hide subtle patterns. Overcrowded row/column labels are the single most common heatmap rejection reason.

## Case 2: Boxplot — No Individual Data Points

**Figure Type:** Boxplot comparing groups (Python/seaborn)
**Target Journal:** Cell Reports

**Problem:** Boxplot showed only boxes and whiskers, no individual data points. Small sample size (n=4 per group).

**Reviewer Comment:** "With n=4 per group, boxplots alone are insufficient. Please show individual data points to allow assessment of the underlying distribution."

**Fix:**
1. Overlaid `stripplot` (or `swarmplot`) on top of boxplots with `alpha=0.7`
2. Used `palette` matching the box colors
3. Added exact n values to axis labels: `"Wild-type (n=4)"`, `"Mutant (n=4)"`

**Lesson:** For n < 10 per group, always show individual data points. Boxplots with small n can hide bimodal distributions or outliers that change the statistical interpretation. This is now a standard expectation across Cell Press journals.

## Case 3: Volcano Plot — Missing Significance Thresholds

**Figure Type:** Volcano plot (Python/matplotlib)
**Target Journal:** Nature Communications

**Problem:** Volcano plot showed all points in one color with no significance or fold-change thresholds marked.

**Reviewer Comment:** "Please indicate the significance threshold (adjusted p-value < 0.05) and fold-change cutoff on the volcano plot. Key genes of interest should be labeled."

**Fix:**
1. Added horizontal dashed line at `-log10(0.05)` for adjusted p-value threshold
2. Added vertical dashed lines at `log2FC = ±1` for fold-change cutoff
3. Color-coded points: grey (NS), blue (significant + low FC), red (significant + high FC)
4. Labeled top 10 genes by significance using `ax.annotate` with leader lines

**Lesson:** A volcano plot without thresholds is just a scatter plot. Reviewers expect to see the filtering criteria visualized on the plot itself. Gene labeling should be selective — label only the top hits plus any genes of specific biological interest.

## Case 4: Multi-Panel Figure — Inconsistent Styling

**Figure Type:** 4-panel composite (Python/matplotlib)
**Target Journal:** Science Advances

**Problem:** Four panels generated by different scripts with slightly different font sizes, color palettes, and axis styles. Inconsistency was visible even at thumbnail size.

**Reviewer Comment:** "The figure panels appear to have been generated separately with inconsistent formatting. Please ensure uniform styling across all panels."

**Fix:**
1. Created a shared `mpl.rcParams` setup block applied before any panel generation
2. Defined a global color dictionary used across all panels
3. Used `gridspec` to enforce equal panel dimensions
4. Applied consistent panel labels (a, b, c, d) in identical position and font

**Lesson:** Multi-panel figures must look like one unified composition, not four separate figures taped together. A shared style block, color dictionary, and layout grid are non-negotiable.

## Case 5: Bar Chart — Hidden Data Distribution

**Figure Type:** Bar chart with error bars (R/ggplot2)
**Target Journal:** eLife

**Problem:** Bar chart showed mean ± SEM for RNA-seq validation qPCR data (n=3). No individual data points visible.

**Reviewer Comment:** "eLife policy requires showing individual data points for experiments with n < 10. Please revise."

**Fix:**
1. Switched from `geom_bar(stat="summary")` to `geom_col(data=means)` + `geom_point(data=raw, position=position_jitter(width=0.1))`
2. Used `geom_errorbar` for SEM
3. Color-matched points to bars

**Lesson:** eLife and several other journals now explicitly require individual data points for small-n experiments. This is becoming an industry-wide standard. Default to showing points unless you have a specific reason not to.

## Case 6: Line Plot — Inadequate Contrast

**Figure Type:** Multi-line time series (Python/matplotlib)
**Target Journal:** Cell

**Problem:** Six treatment groups plotted as colored lines, but three colors were too similar (three shades of blue). Reviewer couldn't distinguish groups.

**Reviewer Comment:** "The color choices for the different treatment groups are difficult to distinguish in print. Please use more distinctive colors or add line style differentiation."

**Fix:**
1. Reduced palette from 6 colors to 3 semantically meaningful colors + 2 linetypes (solid vs dashed for pairwise comparisons)
2. Used direct annotation (label on each line) instead of legend
3. Added subtle vertical shading to separate experimental phases

**Lesson:** More than 4 colors on one plot becomes difficult to track. Use linetype, direct labeling, or panel faceting to reduce the color count. When colors must differ, verify they're distinguishable in greyscale print.

## Case 7: UMAP — Unlabeled Clusters

**Figure Type:** UMAP/t-SNE visualization (R/ggplot2 or Python/scanpy)
**Target Journal:** Cell Systems

**Problem:** UMAP plot showed 12 clusters with default scanpy colors but no cluster labels or biological interpretation on the figure.

**Reviewer Comment:** "The UMAP clusters need to be labeled with their cell type identities. A legend alone is insufficient — please add direct labels or at minimum annotate major populations."

**Fix:**
1. Added cluster identity labels at centroid positions using `geom_text` / `ax.annotate`
2. Used a custom qualitative palette (not scanpy default)
3. Added a small inset showing marker gene expression for key populations
4. Reduced point size for better visibility of overlapping populations

**Lesson:** Clustering figures in single-cell papers need biological interpretation on the figure, not just in the caption. Direct label major populations. Reduce point size when >50K cells — consider rasterization or contour plots.

## Case 8: Correlation Heatmap — Missing Values

**Figure Type:** Correlation matrix (Python/seaborn)
**Target Journal:** Nature Methods

**Problem:** Correlation heatmap showed only the lower triangle. The upper triangle was empty (not masked), leaving white space that looked like an error.

**Reviewer Comment:** "The upper triangle of the correlation matrix appears to contain missing data. Please either mask it properly or show the full matrix."

**Fix:**
1. Used `np.triu` mask with a neutral grey fill (`#F0F0F0`) for the upper triangle
2. Added correlation values as text annotations in each cell (fontsize=5)
3. Applied custom diverging colormap with explicit center at 0

**Lesson:** If masking part of a symmetric matrix, make the mask visually distinct from "no data." A neutral grey fill signals intentional masking. White space reads as missing data.

## Case 9: Phylogenetic Tree — Illegible Tip Labels

**Figure Type:** Phylogenetic tree (R/ggtree)
**Target Journal:** Nature Ecology & Evolution

**Problem:** Tree with 200+ tips had all tip labels shown at default font size. Labels were completely illegible at print size.

**Reviewer Comment:** "Tip labels are unreadable. Please increase font size or show only taxonomically informative labels."

**Fix:**
1. Kept only family/genus-level labels for major clades
2. Added colored clade highlighting for taxonomic groups of interest
3. Moved full tip labels to a supplementary table
4. Increased label font size to 6pt for the retained labels

**Lesson:** Phylogenetic trees with >50 tips should not label every tip in the main figure. Select labels that support the biological narrative. Provide full labels in supplementary materials.

## Case 10: Schematic/Model Figure — Inconsistent Visual Language

**Figure Type:** Biological model schematic (BioRender/Illustrator)
**Target Journal:** Nature Cell Biology

**Problem:** Schematic mixed hand-drawn elements, BioRender icons, and text boxes with different font families, creating a disjointed visual.

**Reviewer Comment:** "The model figure would benefit from a more unified visual style. Different graphical elements appear to come from different sources."

**Fix:**
1. Rebuilt entire schematic in a single tool (BioRender) for visual consistency
2. Used a unified color palette: all proteins in one set of colors, all cellular structures in another
3. Standardized arrow styles (activation = solid arrowhead, inhibition = T-bar) with consistent line weights
4. Applied Arial font to all text labels at uniform size

**Lesson:** Schematic figures are judged on visual coherence just as data figures are. Mixing visual styles from different tools is immediately noticeable. Build schematics in one tool with a defined visual system.
